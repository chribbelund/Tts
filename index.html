        Replay

        Press or ↻ Replay to hear the last message again. Each press goes one message further back, then reading carries on in order up to where it was. New messages wait until the replay is over. The ↻ next to a read message replays just that one.

        Say a different name for a chatter, in their messages, in replies and in @mentions. Click a name in chat to set one without coming here, which is also how to give one to a YouTube or TikTok chatter.

          Bits

          bits are read before everything else (0 = off)
          bits can pick a voice effect (0 = off)

          The effect is the first word after the cheer: Cheer200 robot hello chat. Effects: chipmunk, giant, robot and echo. Robot and echo need neural voices; system voices only change pitch.

          Channel points

          Twitch only shows a redemption in chat when the reward asks the viewer to type something, so turn on Require Viewer to Enter Text for these rewards in your Twitch dashboard.
